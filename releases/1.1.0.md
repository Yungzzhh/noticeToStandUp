# 1.1.0

Build：2

## Added

- 新增工作计时暂停与继续；暂停状态可以跨应用重启、锁屏和休眠保留。
- 新增“版本与更新…”入口，显示版本号、Build 编号和本版本更新摘要。
- 新增工作时长与休息时长设置，并持久化用户选择。
- 菜单、遮罩和通知文案跟随当前时长配置。

## Fixed

- 将休息遮罩的主标题、倒计时和进度条固定在每块屏幕正中间。
- 将活动建议和长按结束控件移到底部，避免影响主视觉居中。
- 修复长按结束休息会退出整个应用的问题；现在会重新开始完整工作计时，
  应用继续在菜单栏运行。
- 修复构建脚本打印中文版本信息时可能以非零状态结束的问题。
