# 站立提醒

一个原生 macOS 菜单栏应用，用明确、不可普通跳过的休息遮罩避免久坐。

本仓库同时包含行为一致的 Windows 原生应用。两端共享产品行为，但分别使用适合
各自系统的 UI 和生命周期 API：macOS 使用 Swift/AppKit/SwiftUI，Windows 使用
C#/.NET 8/WPF。Windows 使用说明见
[windows/README.md](windows/README.md)。

## 核心行为

- 连续工作达到设置时长后，自动在所有显示器显示站立遮罩。
- 遮罩没有普通关闭、跳过或延后按钮，倒计时结束后自动恢复工作计时。
- 菜单栏持续显示剩余时间，也可以主动提前开始一次完整休息。
- 可以分别设置工作时长和休息时长；保存时保留本轮已经工作的时间。
- 可以暂停和继续工作计时；暂停期间剩余时间保持不变，并且状态会跨重启保留。
- 锁屏或休眠期间不累计工作时间；连续离开电脑达到设置的休息时长后，
  回来会开启新一轮工作计时。
- 计时状态会持久化。应用意外关闭后短时间重新打开，可以继续原进度。
- 提供“登录时自动启动”开关和每日已完成次数。
- 可以从菜单栏查看当前版本、Build 编号和本版本更新摘要。

> “强制”指应用运行时遮罩不可普通关闭。macOS 用户始终可以通过强制退出、
> 关机或终止进程绕过任何普通应用。遮罩底部可以长按 3 秒提前结束本次休息，
> 随后应用会继续运行并重新开始完整的工作计时。

## 构建与运行

需要 macOS 14 或更高版本，以及 Xcode Command Line Tools。

```bash
swift test
bash scripts/build-app.sh
open dist/StandUpReminder.app
```

也可以运行统一入口，它会识别当前系统并选择对应构建脚本：

```bash
bash scripts/build-current-platform.sh
```

在 PowerShell 中也可以使用同一入口：

```powershell
.\scripts\build-current-platform.ps1
```

构建产物位于 `dist/StandUpReminder.app`。建议把它拖入“应用程序”文件夹，
再从菜单栏开启“登录时自动启动”。

## 使用提示

1. 首次运行时允许系统通知。
2. 菜单栏的人形图标旁会显示下一次休息倒计时。
3. 从菜单栏选择“计时设置…”，分别调整工作和休息时长。
4. 选择“暂停工作计时”可以冻结当前工作倒计时，再次选择即可继续。
5. 选择“版本与更新…”可以查看版本号、Build 编号和更新摘要。
6. 休息开始后，核心倒计时会固定显示在每块屏幕的正中间。
7. 离开座位走动、活动肩颈和手腕，并眺望远处。
8. 需要提前结束时，在遮罩底部长按 3 秒；应用会重新开始工作计时。
